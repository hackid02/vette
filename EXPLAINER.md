# VETTE 🛡️ — Explain it to anyone in 30 seconds

## The one-liner
**"Every agent makes promises. Vette checks — and when something's wrong, Vette fixes it."**

## Short version
AI agents are about to control real money (trading, moving crypto, posting). Nobody answers the scary question: *"Is this agent actually doing what it promised?"* A buggy or hacked agent doesn't send a warning — it just drains.

VETTE is the agent that vets agents. Three moves:

1. **AUDIT** 🕵️ — give it any AI agent (website, X, or wallet address). It reads what the agent *promised*, checks what it *actually did* on the blockchain, and gives a verdict: ✅ honest, ⚠️ drifting, or 🚨 dangerous — every claim backed by a real transaction.
2. **GUARD** 🛡️ — watches your own wallet 24/7. A sketchy permission or suspicious movement appears → plain-English alert, severity score, no code to decode.
3. **KILL** ⚡ — one click and it revokes the dangerous permission live on the blockchain. It doesn't just warn you. It fixes it.

## Why it's clever
- Other hackathon entries analyze *tokens* and *wallets*. Nobody built an agent that checks *agents*.
- Nobody built an agent that *acts*. Vette does: warn → click → threat gone, onchain.
- The judges run crypto exchanges. "Is this agent safe?" is their industry's #1 question.
- It's an agent that vets agents — on a platform whose whole job is vetting agents.
